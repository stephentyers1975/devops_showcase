# DevOps Showcase Project

## Overview

Welcome to the DevOps showcase Project! This project is to showcase and experiment with various DevOps practices, including CI/CD, Infrastructure as Code, containerization, container orchestration and monitoring. 

This project is based of "The Dynamic Devops Roadmap" website ideas and it will divided up into 5 phases. Each phase will build on the previous and steadily integrate more features and practices
